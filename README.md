# discourse-text-jumble

A Discourse theme component that shows an idle screensaver below the header.
It pulls a paragraph from a random visible topic and progressively rearranges
the letters into geometric, sorting, spiral, and slot-machine-like motion.

## Settings

- `text_jumble_enabled`
- `text_jumble_idle_seconds`
- `text_jumble_topic_source`
- `text_jumble_min_paragraph_length`
- `text_jumble_cycle_seconds`
- `text_jumble_animation_mode`
- `text_jumble_fallback_text`
